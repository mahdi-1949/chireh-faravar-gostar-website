# نمونه‌کار چیره فرآور گستر

وب‌سایت فارسی و راست‌چین برای معرفی تجهیزات آزمایشگاهی فرآوری مواد معدنی، با طراحی واکنش‌گرا و صفحات مستقل.

## امکانات

- صفحه اصلی، کاتالوگ و صفحه اختصاصی ۲۴ محصول
- جست‌وجو و فیلتر گروه محصولات
- مقایسه حداکثر سه دستگاه با ذخیره انتخاب‌ها در مرورگر
- راهکارهای تجهیز آزمایشگاه و سناریوهای پیشنهادی
- خدمات، درباره ما، تماس، پرسش‌های متداول و حریم خصوصی
- دانشنامه و شش راهنمای کاربردی
- کاتالوگ قابل چاپ و دانلود
- آماده‌سازی درخواست پیش‌فاکتور برای ارسال ایمیل یا دانلود متن

## اجرای محلی

هیچ نصب بسته یا مرحله ساختی لازم نیست. با Python 3 اجرا کنید:

```sh
python -m http.server 8000 --directory dist
```

سپس `http://localhost:8000/` را باز کنید. برای حفظ عملکرد مسیرها، پوشه `dist` باید ریشه وب‌سرور باشد.

## ساختار

- `dist/`: تمام صفحات و فایل‌های آماده میزبانی
- `dist/assets/style.css`: سبک‌ها و چیدمان واکنش‌گرا
- `dist/assets/app.js`: جست‌وجو، فیلتر، مقایسه و فرم‌ها
- `dist/assets/data.js`: اطلاعات محصولات و دسته‌بندی‌ها
- `dist/products/`: صفحه‌های اختصاصی دستگاه‌ها
- `dist/knowledge/`: دانشنامه و مقاله‌ها
- `pages.json`: فهرست مسیرهای اصلی
- `check.py`: بررسی پیوندها، فایل‌های داخلی و ساختار عنوان صفحات

## بررسی

```sh
python check.py
node --check dist/assets/app.js
```

## ویرایش و انتشار

فایل‌های HTML، CSS و JavaScript مستقیماً قابل ویرایش‌اند. محتوای پوشه `dist` را در ریشه دامنه یا یک میزبان استاتیک قرار دهید. لینک‌ها از ریشه دامنه شروع می‌شوند؛ برای انتشار زیر مسیر مخزن در GitHub Pages باید پیشوند مسیرها تنظیم شود. این مخزن به‌تنهایی GitHub Pages را فعال نمی‌کند.

## رفتار فرم‌ها و محدودیت نسخه نمایشی

فرم پیش‌فاکتور به سامانه فروش یا پایگاه داده متصل نیست. متن را در مرورگر آماده می‌کند و با انتخاب ارسال، برنامه ایمیل باز می‌شود. ارسال نهایی باید توسط کاربر انجام شود. سناریوهای تجهیز، پروژه اجراشده یا سابقه مشتری نیستند. فایل `robots.txt` برای جلوگیری از نمایه‌سازی این نسخه نمایشی تنظیم شده است.
